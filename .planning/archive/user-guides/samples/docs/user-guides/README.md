# Leave Planner user guides

These guides show how to use Leave Planner, where employees ask for time off and managers decide on it. Each one is for a different reader.

- [Getting started with Leave Planner](getting-started.md): for everyone new. Signing in, finding your way and a first request.
- [Leave Planner for employees](employee.md): checking your balance, asking for leave, following requests, finding colleagues and changing settings.
- [Leave Planner for managers](manager.md): finding the requests waiting for you and approving or declining them.
